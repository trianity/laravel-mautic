# Codex handoff

This directory is an implementation brief, not runtime configuration. Root `AGENTS.md`
is automatically discoverable by Codex; these files provide explicit project context.

Read `STATE.md`, `PROJECT.md`, `../docs/ARCHITECTURE.md` and `ROADMAP.md`. Start a fresh
local session with `prompts/00-resume.md`, then execute one numbered milestone at a time.
Prompts are English for direct use with Codex. Finish each milestone with relevant
checks and a concrete state update before continuing to the next one.

`STATE.md` is the handoff record. Keep implemented behavior, verification evidence,
limitations and the next task accurate. Never mark a roadmap task complete based
only on documentation or mocked HTTP if real-server validation is required.
