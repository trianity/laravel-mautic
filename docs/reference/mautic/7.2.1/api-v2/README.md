## Extraction

The installed API Platform console exporter was used, after inspecting
`php bin/console help api:openapi:export`. From the Mautic installation root, the exact
command was:

```console
php bin/console api:openapi:export --spec-version=3 \
  --output=/home/holbok/web/packages/laravel-mautic/docs/reference/mautic/7.2.1/api-v2/openapi.json \
  --no-interaction --no-ansi
```

The command completed successfully and wrote `openapi.json`. Although the command asks
the exporter for major version 3, this API Platform version emits OpenAPI 3.2.0. No HTTP
credentials are part of the command or artifact.

The export boots the installed application and therefore depends on that installation's
Composer packages, environment, database availability, enabled bundles and discovered
API resources. The CLI export does not require a browser session, Basic Auth or OAuth
credentials. HTTP access to `/api/v2` is separately protected by the installed Mautic
security configuration and operation permissions; successful generation does not prove
that a particular principal can call an operation.

Relevant installed sources are:

- `docroot/app/config/config.php`: API Platform title/version, documentation, pagination,
  PATCH, representation and error formats.
- `docroot/app/config/routing.php`: imports API Platform routes below `/api/v2/`.
- `docroot/app/config/security.php`: protects `/api/v2` through the Mautic API firewall.
- `docroot/app/bundles/LeadBundle/Entity/Lead.php`: contact `ApiResource` operations,
  permission expressions and serialization groups.
- `docroot/app/bundles/LeadBundle/Entity/LeadList.php`: segment resource operations and
  serialization groups.
- `vendor/api-platform/core/src/OpenApi/Command/OpenApiCommand.php`: the supported
  `api:openapi:export` command and its options.

## Validation and safety review

`openapi.json` parsed as JSON and has the expected OpenAPI root structure. All 456
distinct `$ref` values are local document references, all resolve, and no external
reference was found. The artifact is not HTML, a redirect, login response or
authentication error.

A text scan found no private-key markers, authorization headers, bearer-token values,
cookies, local `mautic.test` origin, or email-address-shaped values. Schema property
names such as password or token are API descriptions, not captured credentials. No
real contact record or response payload was used to create the export.
